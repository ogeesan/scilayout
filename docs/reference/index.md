# API reference

`scilayout.figure()` creates a figure.
The classes you work with are also available straight from the package, for example `scilayout.ScaleBar`, and from these modules:

| Module | Contents |
| --- | --- |
| [`scilayout.classes`](classes.md) | `SciFigure`, `PanelAxes`, `PanelLabel`, `FigureText` |
| [`scilayout.scalebars`](scalebars.md) | `ScaleBar`, `LinkedScaleBar` |
| [`scilayout.stats`](stats.md) | `StatsLine` |
| [`scilayout.style`](style.md) | style parameters: `params`, `use`, `reset` |
| [`scilayout.locations`](locations.md) | conversions between cm, inches and figure fraction |
| [`scilayout.types`](types.md) | `Extent` and `Bound`, and their unit aliases |

Anything not listed here, including the modules `scilayout.base` and `scilayout.grid`, is internal and may change without notice.
To read how locations are described see [Locations and coordinates](../coordinates.md).

::: scilayout.figure
